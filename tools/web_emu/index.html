Keyboard: Esc HOME (hold: the menu)  |  G GLO (hold: the Mix grid)  |  ` FX (hold: the dub pads)  |  ← → OCT- / OCT+  |  ↑ ↓ SELECT  |  PgUp PgDn PRESETS  |  Space PLAY, Enter REC  |  keys Z S X D C .. and Q W 3 E 4 ..  |  right-click a button or key: held until right-clicked again

FLASH SUITE TO HARDWARE

Writes the pinned build/felucca.fwsc to an FM-1 on USB with SLOOP's own installer (WebMIDI SysEx). Build it with ENABLE_DUB_PREAMP=1 ./build.sh, then pin it with node tools/web_emu/pkg_manifest.mjs. Chrome or Edge; connect the FM-1 straight to this computer and close other MIDI apps. Do not unplug it while writing. If an install ever fails and the FM-1 does not start, recovering it needs a Transporter. Custom firmware, no warranty.
